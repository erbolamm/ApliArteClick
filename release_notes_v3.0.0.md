# 🚀 Version 3.0.0 - Soporte Multiplataforma y Control Avanzado

## ✨ Novedades Destacadas

### 🌍 Ahora en Windows

- **Soporte Oficial**: ApliArte Click Pro ya está disponible para Windows 10 y 11.
- **Indicador Nativo**: Nuevo sistema de previsualización visual con un círculo azul pulsante nativo (C++ Win32) que indica exactamente dónde se realizará el clic sin interferir con tus ventanas.
- **Rendimiento Optimizado**: Implementación nativa ligera y ultra rápida.

### 🔄 Control de Flujo Avanzado

- **Bucles (Loops)**: Agrupa acciones y repítelas N veces.
- **Drag & Drop**: Arrastra acciones dentro de bucles para anidarlas fácilmente.
- **Reordenamiento**: Usa el icono ☰ para reorganizar acciones de forma intuitiva.
- **Stop & Pause**: Detén la ejecución o añade pausas personalizadas en puntos específicos de tu flujo.

### 🎨 Interfaz y UX Premium

- **Info Screen Mejorado**: Guía visual detallada con emojis y ejemplos prácticos.
- **Atajos Inteligentes**: Visualización correcta de modificadores (ej. "Alt + B" en lugar de solo "B").
- **UI Limpia**: Espaciado y diseño refinado para una experiencia profesional.

## 📥 Instalación

### 🪟 Windows (Recomendado)

**Instalación rápida vía PowerShell:**

```powershell
iwr -useb https://raw.githubusercontent.com/erbolamm/ApliArteClick/main/install.ps1 | iex
```

**Descarga manual:**
Descarga `ApliArteClickPro-Windows-v3.0.0.zip` abajo, extráelo y ejecuta el archivo `.exe`.

### 🍎 macOS

**Instalación rápida vía Terminal:**

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/erbolamm/ApliArteClick/main/install.sh)"
```

**Descarga manual:**
Descarga `ApliArteClickPro-macOS-v3.0.0.zip` abajo y muévelo a tu carpeta de Aplicaciones.
